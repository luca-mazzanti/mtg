(English printings) among all printings of that name in the era shown, so the real value lies somewhere in it.
"(1 printing found)" means only one candidate matched. Scrafty was corrected to Next Destinies 74/99, because no
Emerging Powers Scrafty exists. Team Plasma Dark Trio (Plasma Freeze 102/116) is still unpriced because the API returned nothing for it.
